# Functionality

What the Leanpay Hyva module does for buyers on Hyva shops. The module only draws and wires; the payment, the installment plans, the promotions and the admin settings belong to the base plugin ([leanpay-integration](https://github.com/magebitcom/leanpay-integration)).

- [Leanpay at Hyva Checkout](checkout.md): the payment method, how its installment box follows the order total, and how Place Order sends the buyer to Leanpay.
- [Installment badge on Hyva pages](installment-badge.md): the badge and calculator on product pages, listings and the checkout, the two widget designs, variant promotions and the settings that control them.

How the module is built is in [architecture](../architecture/README.md).
